# 06_Anexos

Material complementario adicional al informe final que no encaja directamente en las carpetas metodológicas anteriores. Incluye, por ejemplo:

- Documentación técnica extendida.
- Notas metodológicas de soporte.
- Referencias a archivos que no pudieron publicarse completos en el repositorio (por tamaño, privacidad o restricciones institucionales), junto con el enlace externo donde se alojan (Google Drive, Zenodo, etc.).

## Estructura sugerida

```
06_Anexos/
├── documentacion_tecnica/
├── notas_metodologicas/
└── enlaces_material_externo.md
```
