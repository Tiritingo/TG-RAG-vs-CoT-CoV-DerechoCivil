# TG-RAG-vs-CoT-CoV-DerechoCivil

Repositorio del trabajo de grado de Maestría en Ciencia de Datos sobre la comparación entre un sistema RAG estándar y una arquitectura agéntica con razonamiento explícito y verificación iterativa para tareas de interpretación jurídica.

## Descripción
Este repositorio centraliza el código, los notebooks, la documentación técnica y los materiales de soporte asociados al desarrollo experimental del proyecto. El objetivo es facilitar la organización del trabajo, la trazabilidad de los experimentos y la reproducibilidad de los resultados.

## Objetivo del proyecto
Evaluar comparativamente el desempeño de un sistema de Generación Aumentada por Recuperación (RAG) estándar y una arquitectura agéntica con razonamiento explícito y verificación iterativa en tareas de interpretación del derecho contractual civil colombiano.

## Estructura del repositorio
- `01_Notebooks/`: notebooks principales del proyecto.
- `02_Scripts/`: scripts auxiliares de extracción, limpieza, preparación y evaluación.
- `03_Data_Sample/`: muestra reducida de datos permitidos para publicación.
- `04_Docs/`: documentación técnica, notas metodológicas y material de referencia.
- `05_Results/`: tablas, métricas, gráficas y resultados comparativos.
- `06_Anexos/`: material complementario para el informe final.

## Requisitos generales
- Python 3.10 o superior.
- Entorno virtual recomendado.
- Dependencias instaladas según el archivo de requisitos o según la documentación de cada notebook.
- Acceso a Google Colab o un entorno compatible si se ejecutan notebooks en la nube.

## Uso recomendado
1. Revisar primero la documentación del repositorio.
2. Ejecutar los notebooks en el orden en que aparecen en la carpeta `01_Notebooks`.
3. Validar que las rutas de archivos coincidan con la estructura del repositorio.
4. Consultar `02_Scripts` para tareas automatizadas y `05_Results` para revisar salidas y métricas.
5. Verificar los anexos para información adicional sobre código, corpus y material de soporte.
